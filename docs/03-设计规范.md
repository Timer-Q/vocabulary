# 设计规范

> 配套文档：[PRD.md](../PRD.md)  
> 适用：微信小程序 + 抖音小程序，Taro + UnoCSS  
> 设计原则：现代化 / 流畅 / 减压 / 可访问

---

## 1. 设计语言

- **关键词**：清新、专注、有节奏感、不焦虑
- **隐喻**：词根像树根，记忆像生长
- **风格**：玻璃拟态点缀 + 大留白 + 渐变高光，远离"老式教育产品"的拥挤感

---

| `--brand-gradient` | `linear-gradient(135deg, #1B2A4E 0%, #2E4374 100%)` | 主渐变 |

## 4. 间距与圆角

### 4.1 间距尺度（rpx）

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 48`，禁止使用奇数 padding。

### 4.2 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-sm` | 8rpx | 标签、徽章 |

| `--radius-lg` | 24rpx | 卡片 |
| `--radius-xl` | 32rpx | 主单词卡 |
| `--radius-full` | 9999rpx | 圆形 |

### 4.3 阴影

## 5. 组件规范

### 5.1 单词卡 WordCard

- 圆角 `--radius-xl`，阴影 `--shadow-lg`
- 顶部：拆词三段着色 + 音标
- 中部：主释义 + 词性
- 底部：手势提示（左滑陌生 / 右滑熟练 / 上滑词根 / 下滑收藏）
- 翻面：例句首句预览
- 状态：正常 / 拖拽中（轻微缩放 0.98）/ 飞出（透明度+位移）

### 5.2 词根标签 RootTag

- 圆角 `--radius-md`，玻璃拟态背景
- 高亮可点击，长按加入"词根学习清单"

### 5.3 进度环 ProgressRing

- 五等分弧线代表五级熟练度
- 当前级别填充品牌渐变
- 点击显示熟练度说明

### 5.4 例句卡 ExampleCard

- 顶部 4rpx 色条 = 例句层级色
- 来源徽章 + 出处（年份/真题/影视）
- 单词级跟读高亮（卡拉 OK 风格）
- 中文翻译可隐藏（默认隐藏，点击显示）

### 5.5 思维导图节点 MindmapNode

- 词根节点：实心圆 + 词根名
- 单词节点：圆角矩形 + 拼写
- 边：曲线，鼠标悬停加粗
- 选中：发光环 + 弹出详情卡

### 5.6 按钮 Button

| 类型 | 用途 |
| --- | --- |
| Primary | 主操作（开始学习） |
| Secondary | 次要操作（跳过） |
| Ghost | 弱操作（取消） |
| Icon | 仅图标按钮（48×48） |

最小可点击区域 88rpx × 88rpx。

## 6. 交互规范

### 6.1 单词卡手势

| 手势 | 行为 | 反馈 |
| --- | --- | --- |
| 左滑 | 标记陌生 | 红色边缘渐显 + 卡片飞向左 |
| 右滑 | 标记熟练 | 绿色边缘渐显 + 卡片飞向右 |
| 上滑 | 进入词根详情 | 卡片向上展开 |
| 下滑 | 收藏 | 心形图标弹出 |
| 双击 | 朗读 | 朗读图标脉冲 |
| 长按 | 加入生词本 | 触觉反馈 + Toast |

### 6.2 微动效

| 场景 | 动效 |
| --- | --- |
| 拆词 | 各段从中心扩散，stagger 80ms |
| 答对 | 淡淡的烟花 + 成功色边缘 |
| 答错 | 卡片轻微抖动（不红屏） |
| 词根高亮 | 派生词链路顺序点亮 |
| 进度更新 | 进度环顺时针转动 600ms |
| 切换标签 | 下划线滑动 200ms |

> 动效统一 `cubic-bezier(0.4, 0, 0.2, 1)`，时长 200/300/600 三档。

### 6.3 加载状态

- 首屏：骨架屏（不要纯转圈）
- 切换：原位置保持，淡入新内容
- 失败：友好插画 + 重试按钮

### 6.4 空状态

- 配置插画 + 一句鼓励文案 + 主操作 CTA
- 避免单纯的"暂无数据"

### 6.5 触觉反馈

- 答对 / 答错 / 长按 / 收藏：轻量震动（小程序原生 API）

## 7. 减压设计原则

| 原则 | 实践 |
| --- | --- |
| 不展示绝对错误数 | 用进度环 + 成长曲线代替 |
| 鼓励代替警示 | "今日小步前进" 代替 "还差 X 个" |
| 量过大可减压 | 弹窗"今日仅复习核心 N 个" |
| 失败温和 | 抖动 + 浅色边，无红屏弹窗 |
| 连续打卡断更不羞辱 | "回来真好"代替"已断 X 天" |

---

## 8. 可访问性

- 文本最小对比度 4.5:1，主操作 7:1
- 触控区域不小于 88rpx
- 不使用颜色作为唯一信息通道（搭配形状/图标）
- 支持系统级"减少动画"开关
- 支持大字号模式（自适应布局）
- 朗读控制清晰可见

---

## 9. 适配规则

### 9.1 尺寸基准

- 设计稿基准：`750rpx` 宽（iPhone 6 等价）
- 安全区适配：使用 `env(safe-area-inset-*)`

### 9.2 暗黑模式

- 跟随系统，提供手动切换
- 所有颜色必须在亮/暗下都可读
- 媒体素材准备暗色变体（图片可适当降低饱和度）

### 9.3 双端差异

| 项目 | 微信 | 抖音 |
| --- | --- | --- |
| 渲染层 | Skyline | WebView |
| 顶部胶囊 | 系统胶囊预留 | 标准导航 |
| 底部安全区 | iOS 大部分需预留 | 同 |
| TabBar | 自定义可使用 Skyline 优化 | 标准实现 |

抖音如不支持某些 Skyline 能力（如 `shared-element`），降级为普通过渡动画。
