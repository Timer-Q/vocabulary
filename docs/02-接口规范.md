# 接口规范

> 配套文档：[PRD.md](../PRD.md) · [数据字典](01-数据字典.md)  
> 协议：HTTPS + JSON  
> 域名：`https://api.cigenxia.com`（示意）  
> 鉴权：`Authorization: Bearer <supabase-access-token>`  
> 版本：`/v1/...`

---

## 1. 通用约定

### 1.1 请求

```http
POST /v1/learn/answer HTTP/1.1
Host: api.cigenxia.com
Authorization: Bearer <supabase-access-token>
Content-Type: application/json
X-Platform: weapp        // weapp | tt
X-Client-Version: 1.0.0
X-Request-Id: 8d2f...    // UUID，幂等与链路追踪

{ "wordId": 1234, "result": "known", "responseMs": 1820 }
```

### 1.2 响应

```json
{
  "code": 0,
  "message": "ok",
  "data": { /* ... */ },
  "requestId": "8d2f..."
}
```

### 1.3 错误码

| 区间 | 含义 |
| --- | --- |
| 0 | 成功 |
| 1xxx | 通用错误（参数/鉴权/限流） |
| 2xxx | 业务错误（学习/例句/AI） |
| 5xxx | 服务端错误 |

| 错误码 | message | 说明 |
| --- | --- | --- |
| 1001 | invalid_params | 参数校验失败 |
| 1002 | unauthorized | 未登录或 token 失效 |
| 1003 | forbidden | 无权限 |
| 1004 | rate_limited | 频控 |
| 2001 | word_not_found | 单词不存在 |
| 2002 | example_pending | 例句审核中 |
| 2003 | ai_quota_exceeded | AI 额度用尽 |
| 2004 | ad_reward_invalid | 激励视频回调校验失败 |
| 5001 | internal_error | 服务异常 |

### 1.4 分页

```
?cursor=xxx&limit=20    // 推荐游标分页
?page=1&limit=20        // 列表页可用偏移分页
```

返回：

```json
{ "list": [], "nextCursor": "xxx", "hasMore": true }
```

### 1.5 命名

- URL：`kebab-case`
- 字段：`camelCase`
- 时间：ISO 8601 字符串 `2026-05-06T10:00:00Z`

## 2. 鉴权 Auth

### 2.1 双端登录

```
POST /v1/auth/login
```

请求：

```json
{
  "platform": "weapp",   // weapp | tt
  "code": "0a1b2c3d",    // wx.login / tt.login 拿到的 code
  "encryptedData": "...",// 可选，用于解密手机号/用户信息
  "iv": "..."
}
```

响应：

```json
{
  "code": 0,
  "data": {
    "token": "<supabase-access-token>",
    "refreshToken": "<supabase-refresh-token>",
    "expiresIn": 604800,
    "user": {
      "id": 10086,
      "nickname": "学英语的小王",
      "avatarUrl": "https://...",
      "platform": "weapp",
      "isNew": true
    }
  }
}
```

### 2.2 刷新

```
POST /v1/auth/refresh
```

刷新逻辑使用 Supabase Auth refresh token；BFF 可代理刷新，也可由前端 Supabase 客户端直接刷新（MVP 建议由 BFF 代理，避免平台差异扩散）。

    "audioUsUrl": "https://cdn/.../us.mp3",
    "pos": [{ "pos": "n", "meaning": "重建；改造" }],
    "splitPattern": [
      { "form": "re", "type": "prefix", "meaning": "再", "rootId": 11 },
      { "form": "con", "type": "prefix", "meaning": "共同", "rootId": 12 },

### 4.2 拆词（AI 兜底）

```
POST /v1/words/split
```

```json
{ "spelling": "obfuscate" }
```

返回结构同 `splitPattern`，附 `source: "cache" | "ai"`。

### 4.3 长按查词

```
GET /v1/words/lookup?q=struct
```

返回 Top 5 候选 + 主释义。

### 4.4 OCR 拍照查词

```
POST /v1/words/ocr
Content-Type: multipart/form-data

file: <image>
```

返回识别到的单词列表（已存在的标记 `inLib: true`）。

## 12. 频控与缓存策略

| 接口 | 频控 | 缓存 |
| --- | --- | --- |
| `GET /v1/words/:spelling` | 60/min/user | Redis 7 天 |
| `POST /v1/words/split` | 20/day/user | Redis 永久 + 命中率监控 |
| `POST /v1/learn/answer` | 600/min/user | 不缓存 |
| `POST /v1/examples` (UGC) | 5/day/user | 不缓存 |
| `GET /v1/examples` | 120/min/user | Redis 1 天 |

## 13. 双端差异封装（前端）

```ts
// src/platform/index.ts
export interface Platform {
  login(): Promise<{ code: string }>;
  showRewardedAd(scene: string): Promise<{ transId: string }>;
  subscribeMessage(templateIds: string[]): Promise<void>;
  share(payload: SharePayload): void;
}

export const platform: Platform = (process.env.TARO_ENV === 'weapp')
  ? require('./weapp').default
  : require('./tt').default;
```

业务层调用：

```ts
const { code } = await platform.login();
await api.auth.login({ platform: process.env.TARO_ENV, code });
```

## 14. 安全

- HTTPS 全链路
- Supabase Auth access token 作为接口 Bearer token，refresh token 用于续期
- 关键写接口（登录、UGC、广告回调）开启签名校验
- AI 接口用户级频控 + IP 级频控
- 敏感词过滤 + UGC 二审
